Каталог домашніх рецептів

        Завдання 1. Каталог домашніх рецептів
        Розробіть односторінковий застосунок «Каталог домашніх рецептів» за допомогою HTML, CSS і TypeScript.
        
        Користувач повинен мати можливість:
        
        • створювати записи, вказуючи назву, категорію, список інгредієнтів, час приготування та короткий опис;
        
        • переглядати список усіх записів;
        
        • редагувати будь-який існуючий запис;
        
        • видаляти записи після підтвердження;
        
        • шукати рецепти за назвою; фільтрувати їх за категорією.
        
        Усі дані потрібно зберігати в localStorage, щоб після перезавантаження сторінки вони не зникали.
        
        Обов’язково реалізуйте всі CRUD-операції:
        
        • Create — додавання нового запису;
        
        • Read — відображення списку та деталей записів;
        
        • Update — редагування даних запису;
        
        • Delete — видалення запису.
